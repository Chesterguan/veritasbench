~50 lines of Rust per `runner-incremental-persistence.md`. Open
`<output_dir>/scenarios.ndjson` in append mode at start of run; write one
JSON line per scored scenario; final `report.json` aggregation reads from
the NDJSON instead of an in-memory `Vec<ScenarioScore>`.

overnight until this lands.**

already-scored scenarios on next invocation; `report.json` aggregates

## P2 — Methodology rigor (closes specific reader objections from v1.2)

### 4. Trace-ceiling experiment (full-field audit entries)

Add one wrapper variant — or modify an existing one — to populate all 3
audit-entry fields (`actor`, `resource`, `reason`) instead of the
current skeletal `{timestamp, action}` template. Tests whether the
33.1% Trace floor in v1.2 is **structural** (template-side: minimal
fields) or **behavioral** (LLM-can't-generate-the-fields-side).

Without this, a reviewer can dismiss the v1.2 "wrappers move Trace
33.1%" finding as "wrappers we tested produce 1-of-3-fields entries; of
course they hit 33% — that's just 1/3 of the rubric."

### 5. Audit-entry prompt variant

Modify the bare-LLM prompt to explicitly ask for `audit_entries` alongside
`decision`. Per `benchmark-realism-improvements.md` §1. Tests the
*ceiling* of what a bare LLM pipe can produce when prompted, separate
from the *floor* it produces when not prompted.

Disambiguates "0% Trace on bare = pipe-side issue (no place to record)"
from "0% Trace on bare = LLM can't format audit entries when asked."
The architectural claim only holds cleanly if the latter is non-zero.

### 6. Replicate NeMo + Claude DF on a larger sample

Current n=3 dangerous failures, 95% CI ~[0.1%, 1.5%]. One re-run with
a different scenario seed or larger suite tells us whether 0.5% is real
signal or sampling noise on a striking number. Currently published in
v1.2 as "suggestive evidence of a wrapper × LLM interaction" with the
n=3 caveat in-line; v1.3 should either confirm and promote to a settled
finding, or report the regression honestly.

### 7. Cross-LLM transfer at n≥3 LLMs

"Policy degradation depends on LLM tier" v1.2 finding rests on 1 of 3
wrappers (OpenAI Guardrails) and n=2 LLMs. Adding Hunyuan A13B (lower
tier, 70.1% bare) and Qwen3-Max (different lab, frontier tier, 83.3%
bare) under all 3 wrappers = 6 more runs — both already baseline-tested
in Axis A. Either confirms the LLM-tier-dependence pattern across
4–5 LLM tiers, or kills it as a 1-of-3-wrapper artifact.

## P3 — Bigger investments (worth doing but not v1.3-blocking)

### 8. Medical-LLM access

Self-host HuatuoGPT-II-34B / HuatuoGPT-o1-72B / Meditron3-70B / Med42-70B
/ OpenBioLLM-70B on Together.ai or HF Inference Endpoints. Per
`medical-llm-test-plan.md`, all are open-weight; the v1.2 access problem
is hosting, not licensing. ~$300–$500/month while runs are active.

Even one of these tested at full precision would close the v1.2
"medical specialization doesn't help" claim across the right model
class, instead of just the Q4-quantized MedGemma 4B.

### 9. Clinician audit of 100-scenario subset

Closes the "LLM-judged ground truth has sibling bias" caveat that
appears in every v1.2 draft. Recruits a licensed MD/PharmD reviewer for
~100 scenarios, compares their decisions to the LLM-consensus
ground-truth from `scripts/llm_judge_validate.py`. If ≥90% agreement,
keep the LLM-judge ground truth. If <90%, migrate ground truth to the
clinician labels for the audited subset and rescore everything against
that.

### 10. Provider-pinning + quantization metadata

Per `benchmark-realism-improvements.md` §3 and §4. Add `meta.provider`
to per-scenario records by capturing OpenRouter's `provider_name`
response header. Add quantization metadata for local Ollama models via
`/api/show`. Mechanical instrumentation; both currently disclosed as
un-instrumented in v1.2 limitations.

### 11. Full 9 × 4 matrix completion

Every Axis A LLM × every Axis B wrapper. Adds 18 more runs (9 LLMs ×
3 wrappers; bare baselines for all 9 LLMs already in
`outputs/llm_*/`). With persistence fix in place + a nightly job
runner, plausibly fits in 2–3 overnight runs. Closes the n=2 LLMs
caveat for the cross-LLM-transfer claim definitively.

Generates a true 9 × 4 grid for the README and a richer joint-picture
chart in the blog.
